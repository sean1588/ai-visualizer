Mise.Quickstart

From rows to a plate in one pass.

  1. Open the app. No account.
  2. Drop a CSV/JSON file, paste rows, or fetch a public GET URL.
  3. Optional notes nudge the layout. They are guidance, not commands.
  4. Render. A complete-data profile is computed locally. Aggregate facts are sent once for layout; raw rows are not.
  5. Ask The Chef to edit. Transforms (sort, limit) show as chips — they are not magic.
  6. Inspect data health, widget rationale, supporting rows, or the complete recipe before sharing a claim.
  7. Open Analyze to filter the full dashboard, save views, set KPI goals, keep context notes, inspect columns and relationships, scan for sensitive fields, or hand a suggested follow-up to The Chef.
  8. Use Present for a clean review view. Download a dashboard backup when you need to move its rows, recipe, goals, views, notes, and theme to another browser.
  9. Export a PNG, recipe JSON, table CSV / Markdown, or a self-contained interactive HTML file. Recipe links contain layout only.

Recipes can be dropped back onto the plate and run against new data without asking the model again. Saved HTTP dashboards can refresh while open, compare snapshots, and evaluate local thresholds.

Mise records small first-party product events such as “dashboard rendered” and export type. Events never contain rows, field names, URLs, notes, or Chef text. Set mise.telemetry.disabled to 1 in local storage to opt out.
