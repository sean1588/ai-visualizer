Mise.Examples

What people drop in.

  • SaaS weekly metrics — MRR, accounts, NRR, logo churn. Built-in sample on the empty plate.
  • Stripe payouts — the other built-in sample, good for status badges and net vs fees.
  • Public JSON arrays — GitHub commits, civic CSVs, any GET that returns rows. Refresh reuses the recipe.
  • Quoted CSV — product names like "Widget, C" stay one field. RFC-4180, including BOM and blank lines.

These are starting plates, not a promise that the model will always pick the right chart.
